봇이 굴리는 계좌입니다. 평가액은 원화 + 보유 코인을 지금 값으로 친 것입니다.

🚀 실험 트랙 — 자주 거래하며 배우는 중 breakout

이 트랙의 목적은 당장 돈을 버는 게 아니라, 자주 거래해서 데이터를 모으는 것입니다. 과거 데이터 기준 이 전략은 거래당 약 −0.19%로, 월 3천원쯤 수업료를 내는 셈입니다. 대신 한 건당 딱 10,000원만 쓰도록 묶여 있고, 매주 이 표를 보고 "어떤 조건의 거래가 손해였나"를 찾아 규칙을 다듬습니다.

🧪 검증 트랙 — 이 전략이 진짜인지 확인하는 중 rsi2

과거 2년 데이터에서는 잘 통했습니다. 그런데 실제 돈으로도 그런지는 따로 확인해야 합니다. 거래 100건이 쌓이면 처음으로 "진짜다/아니다"를 말할 수 있습니다. 이 전략은 조건이 까다로워 몇 주씩 거래가 없는 것도 정상입니다 — 실험 트랙과는 성격이 다릅니다.

📦 지금 들고 있는 것

실험 트랙은 고점을 따라가다 꺾이면 팔고, 검증 트랙은 정해진 손절·익절선에서 팝니다.

🔍 지금 왜 안 사고 있나

실험 트랙은 "24시간 최고가 돌파 + 거래량 급증" 2가지가 맞아야 사고, 검증 트랙은 조건 3가지가 동시에 맞아야 삽니다. 실험 트랙은 하루 몇 건씩 나오는 게 보통이고, 검증 트랙은 조용한 날이 대부분입니다.

📜 최근 거래

사고 판 것을 한 줄로 묶은 기록입니다. 보라색은 실험 트랙, 파란색은 검증 트랙입니다.

📖 이 봇은 무슨 전략을 쓰나

한 줄 요약 — 트랙이 2개입니다

🚀 실험 트랙(breakout): 지난 24시간 최고가를 거래량이 급증하며 뚫는 순간 사서, 오르는 동안 따라가다 꺾이면 바로 팝니다. 하루 3~10건쯤 거래합니다.

🧪 검증 트랙(rsi2): 오르고 있는 코인이 잠깐 미끄러졌을 때 사서, 제자리로 돌아오면 팝니다. 조건이 까다로워 거래가 드뭅니다.

🚀 실험 트랙 — 살 때·팔 때

살 때 (2가지 동시):

  1. 지난 24시간 최고가를 방금 넘었다 — 이제 막 움직이기 시작한 코인만
  2. 거래량이 평소의 5배 이상 — 진짜 움직임인지 확인

팔 때 (셋 중 먼저 오는 것):

  • 고점에서 꺾이면 — 최고점 대비 일정 폭(2×ATR) 내려오면 자동 매도. 오르는 동안은 계속 따라갑니다
  • 1시간 안에 +0.3%도 못 가면 — 안 가는 돌파는 빨리 회수
  • 최악의 경우 — 산 값에서 일정 폭 밑으로 빠지면 무조건 손절

⚠ 솔직한 사실: 과거 2년 데이터로 재보면 이 전략은 거래당 −0.19%입니다 (수수료·호가 차이 때문). 그런데도 돌리는 이유는, 어떤 조건의 돌파가 통하고 어떤 게 안 통하는지 실제 데이터로 배우기 위해서입니다. 그래서 건당 1만원으로 묶고, 매주 위의 실험 트랙 표를 보며 규칙을 하나씩 다듬습니다.

🧪 검증 트랙 — 살 때·팔 때

살 때 (3가지 동시):

  1. 방금 확 미끄러졌다 — 직전 몇 분이 거의 전부 하락 (RSI2 ≤ 3)
  2. 큰 흐름은 아직 상승 — 추세가 꺾였으면 안 삽니다 (1시간봉 EMA200 위)
  3. 충분히 움직이는 코인이다 — 안 움직이면 수수료도 못 건집니다 (ATR ≥ 0.6%)

팔 때 (4가지 중 먼저 오는 것): 되돌림 끝(가장 흔함, RSI2 ≥ 70) · 익절 +2.5% · 손절 −2.5% · 시간 초과 8시간

어떤 코인을 사나

사는 값과 파는 값의 차이(호가 스프레드)가 작은 코인만 삽니다 — BTC·ETH·XRP·SOL 같은 것들입니다.

거래 한 번의 이익·손해가 0.2% 안팎인데, 어떤 알트코인은 그 값 차이만 0.9%라 사는 순간 이미 집니다. 봇이 10분마다 다시 재서 자동으로 걸러냅니다.
