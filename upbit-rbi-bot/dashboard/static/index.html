한 줄 요약

오르고 있는 코인이 잠깐 미끄러졌을 때 사서, 제자리로 돌아오면 판다.

떨어지는 걸 무작정 사는 게 아닙니다. 오르는 중인 것만 골라서 그게 잠깐 미끄러진 순간만 삽니다. 보통 1시간 안에 사고팝니다.

살 때 — 조건 3개가 전부 맞아야 함
  1. 방금 확 미끄러졌다 — 직전 몇 분이 거의 전부 하락 (RSI2 ≤ 3)
  2. 큰 흐름은 아직 상승 — 추세가 꺾였으면 안 삽니다. 하락 추세에서 사면 그냥 계속 떨어집니다 (1시간봉 EMA200 위)
  3. 충분히 움직이는 코인이다 — 안 움직이면 되돌아와도 수수료 빼면 남는 게 없습니다. 이 조건이 없으면 전략 전체가 마이너스가 됩니다 (ATR ≥ 0.6%)
팔 때 — 4가지 중 먼저 오는 것
  • 되돌림 끝 — 가장 흔한 경우입니다 (RSI2 ≥ 70)
  • 익절 +2.5%
  • 손절 −2.5% — 틀렸다고 인정하고 빠르게 자릅니다
  • 시간 초과 8시간 — 안 돌아오면 돈을 회수합니다
어떤 코인을 사나

사는 값과 파는 값의 차이(호가 스프레드)가 0.10% 이하인 코인만 삽니다 — BTC·ETH·XRP·SOL 같은 것들입니다.

거래 한 번에 기대하는 이익이 +0.18%뿐이기 때문입니다. 어떤 알트코인은 그 값 차이만 0.9%라 사는 순간 이미 집니다. 봇이 10분마다 다시 재서 자동으로 걸러냅니다.
